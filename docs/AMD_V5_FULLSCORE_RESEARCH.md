# 满分目标的后续实验：尚未选出新提交版本

北京时间 2026-11-03，基于已验证产品提交
`b775ded989531f42f4a3b700aa713971fb1912d3` 继续实验。
用户表示该提交尚未正式提测，因此没有该版本的官方分数或 Hidden 指标。
本研究分支仅添加记录，产品源码与上述提交相同；不作为新性能版本推荐提测。

## 目标与范围

全部硬门槛通过之后，综合 SQL 冷建索引加速 B 至少 3.0、综合查询加速
Q 至少 1.5 才能满分。此次尝试 18 组统一参数/构建算法组合，使用同一
gfx1100 / ROCm 7.2.4 实例、现有公开 SIFT 及合法自生成 256 维数据，
配对冻结 V5 基线。最终没有发现可验证达到该目标的候选。

以下数字均为独立 bridge 开发筛选，不是 SQL 冷 DDL 加速或正式分数。
首批方案只做一轮用于快速排除，搜索配置与精简 PQ 配置做两轮；
50 轮候选另用第二种子 Gaussian 数据做三轮。未通过筛选的方案未执行
新的 SQL 验证，不将已验证 perf2 的 SQL 记录嫁接到这些候选。

## 实验结果

| 方案 | Gaussian 开发结果 | 决定 |
| --- | --- | --- |
| 中间图 128、图度数 96、32 轮、8 次入口采样 | 独立建图 3.45×，R@10/100=0.906372/0.842729；同轮通过线为 0.946685/0.894749 | 质量失败，排除 |
| 中间图 128、图度数 64、32 轮、8 次入口采样 | 独立建图 3.77×，R@10/100=0.841089/0.758796 | 质量失败，排除 |
| 中间图 128、图度数 128、32 轮、8 次入口采样 | 独立建图 2.97×，R@10/100=0.935547/0.884990，查询比 0.760 | 质量及查询回归失败 |
| 中间图 192、图度数 128、50 轮、8 次入口采样 | R@10/100=0.952393/0.907388，但查询比 0.746 | 查询回归失败 |
| 迭代 CAGRA 建图，中间图 192/256 | 质量通过，但建图加速仅 0.374/0.274；查询比低于 0.85 | 更慢且查询回归，排除 |
| 精化 IVF-PQ，64/128 probes | R@100 升至 0.915007/0.918650，但建图加速仅 0.415/0.263，显存比 2.13/2.08 | 速度、显存和查询回归失败 |
| 精简 PQ 训练至 5 轮、训练集比例 0.1，8/16 probes | R@100 为 0.840156/0.874976，显存比 1.27/2.21 | 质量及显存失败 |
| 50 轮，入口采样 4，team_size=8 | 首组数据质量通过，独立建图约 1.90×，查询比 0.937 | 进入第二随机种子检查 |

`team_size=16/32`、显式 256 线程块及保留 64 轮的其他组合也保存完整指标。
部分配置在第一组数据的检查通过，但性能与质量余量未形成可推荐的新候选。

50 轮、team_size=8 在第二随机种子的三轮最差 R@10 为 **0.9461181640625**，
同轮通过线为 **0.94587890625**，仅高 **0.0002392578125**。
它通过了这一数据的数学门槛，但低于此前开发采用的额外 0.0015 余量，
没有被选为可提交版本。该额外余量不是官方规则。
