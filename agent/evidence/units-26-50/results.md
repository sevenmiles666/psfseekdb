# MiniVectorDB 第 26～50 项实测

工作版本 `5c965733f0e5dbfe86421449357bf17bf3e59108`。25 项均完成并通过各项断言。记录保留实际运行结果和场景范围。

常规计时使用发布构建。诊断版仅增加路径、计数及同步计时。第 44 项使用独立扫描程序。

[工具证据 JSON](tool-evidence.json) 中列有各原始记录的 SHA-256。
