## 输入修订

- `agent/conversation.json` 为题面默认材料路径；根目录 `conversation.json` 是字节相同的兼容副本。
- `material_summary` 是 Agent 整理的材料范围摘要；`provenance` 说明代码基础、历史材料来源和新增内容来源。
- 历史用户引文、Agent 消息和实验字段原样保留。新增当前会话中用户质疑性能指标、Agent 核对并更正、用户选择旧版的实际片段，以及两次正式任务的结果。
- `evidence_navigation` 提供可定位的 JSON pointer 和精确引文。这些导航不预先指定分数，也不将同一条交互链拆成多个贡献。
- `material-manifest.json` 记录材料字节数、SHA-256、导入内容摘要和旧版运行文件哈希，便于独立核验。它是本仓库的输入完整性清单，不是官方规定的评审输出格式。

使用 Python 3 检查输入完整性：

```sh
python3 tests/check_prompt_material.py
```

校验 UTF-8、顶层对象、128 KiB 上限、重复键、非有限数值、两份副本、材料摘要、引用可定位性及原文匹配，同时检查历史字段与数据库运行文件保持原样。检查通过只证明输入符合这些条件，不等于 Prompt 已获得有效平台分数。

## 尚未解决的评审端状态

两个不同版本的正式任务均返回同一句提示：

> Prompt结果无效、待复核、超出平台0–100范围或缺少材料摘要，本项不参与排名；未截断或换算本地分数。

列表接口和详情接口均未提供本次对应的具体错误、三轮评审报告、材料读取摘要或状态。本次补入的 `material_summary` 便于材料识别，但题面没有规定必须使用这个输入字段，不能断言它就是原报错的根因。

2026-11-12 读取的官方题面（更新时间 2026-11-11）仍采用 `agent-learning-evidence-v3-unbounded`，规定原始评价分不设上限；第 4.4 节允许自由组织输入字段。平台提示中的 0–100 与该口径不一致，需要核对实际评审配置。材料不自行编写、截断或转换 `agent_prompt_score`，也不将未知状态声明为有效。

只有官方重新评测并返回有效状态及分数后，才能确认提示消除。若仍失败，需要赛方提供实际材料读取路径和 SHA-256、具体错误分类、评审规则版本、原始评审状态及材料摘要生成状态。
